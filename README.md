# dsh-welcome-back

DeepSeek Harness 的“欢迎回归 + 今日工作集”插件。

它只在你主动打开一个 DSH 会话时处理该会话：

- 只保存该会话最后一次可见消息的简短快照和时间戳；
- 自动跳过 DSH 的“用量 / 已完成 / 用时 / 时间戳”等界面状态行，以及工具过程卡片；
- 不读取长期记忆、其他会话、外部文件、Git 或系统活动；
- 闲置超过用户设置的阈值后，重新回到此会话时显示回归卡；
- 用户可以点击或直接按 `A`、`B`、`C`、`D`。

## 今日工作集（0.2.0）

默认提醒范围为“仅今日活跃会话”：

- 只有今天出现过实质性消息的会话，才会在下次回到该会话且超过闲置阈值时提示；
- 单纯打开一个历史会话不会把它加入今日工作集，也不会弹出历史闲置提醒；
- 插件不会主动扫描侧栏、逐个弹出、或打扰其他会话；
- 可改为“所有已记录会话”，或改为“仅手动加入的会话”；
- 在设置面板中可把当前会话加入或移出手动工作集。

“今天创建”依赖宿主是否暴露创建时间；本插件不猜测该时间。当前可靠规则是“今天出现过实质消息”。

## 当前原型行为

| 选择 | 行为 |
|---|---|
| `A` | 向当前会话发送“仅依据上一条消息复述明确的任务、约束和期待结果”的请求 |
| `B` | 向当前会话发送“仅依据上一条消息做极简断点汇报”的请求 |
| `C` | 关闭本次回归卡并继续 |
| `D` | 在最短重复提醒间隔内不再提醒当前会话 |

设置通过右下角的 `◷` 按钮打开。可配置总开关、闲置阈值、重复提醒间隔、提醒范围、是否显示时长和欢迎语。

## 安全边界

这是隔离源码原型，尚未安装进 DSH Desktop profile。它没有修改 `D:\soft\dsh-next-home\profiles\desktop`，也没有接触 DSH 会话文件。

安装前必须：

1. 读取 DSH Desktop 当前内核版本；
2. 核对 `package.json` 中 `dsh.engines.dsh`；
3. 备份 desktop profile 的 `package.json` 和 lockfile；
4. 确认 DSH 中没有未完成的重要会话；
5. 通过 DSH Desktop 的插件管理通道安装，而不是直接复制到 profile。
