# dsh-welcome-back

DeepSeek Harness 的“欢迎回归 + 今日工作集”插件。

它只在你主动打开一个 DSH 会话时处理该会话：

- 只保存该会话最后一次可见消息的简短快照和时间戳；
- 自动跳过 DSH 的“用量 / 已完成 / 用时 / 时间戳”等界面状态行，以及工具过程卡片；
- 不读取长期记忆、其他会话、外部文件、Git 或系统活动；
- 闲置超过用户设置的阈值后，重新回到此会话时显示回归卡；
- 用户可以点击或直接按 `A`、`B`、`C`、`D`。

## 今日工作集（0.2.0）

默认提醒范围为“仅今日活跃会话”：

- 只有今天出现过实质性消息的会话，才会在下次回到该会话且超过闲置阈值时提示；
- 单纯打开一个历史会话不会把它加入今日工作集，也不会弹出历史闲置提醒；
- 插件不会主动扫描侧栏、逐个弹出、或打扰其他会话；
- 可改为“所有已记录会话”，或改为“仅手动加入的会话”；
- 在设置面板中可把当前会话加入或移出手动工作集。

“今天创建”依赖宿主是否暴露创建时间；本插件不猜测该时间。当前可靠规则是“今天出现过实质消息”。

## 笔记本界面优化（0.2.1）

- `◷` 设置按钮默认放在左下角，避免遮住 DSH 右下角的发送按钮；
- 可在设置中选择左上、右上、左下、右下，或恢复到上次拖放的位置；
- 可直接拖动 `◷` 到任意位置，位置会保存在浏览器本地；
- 回归卡的上一条消息区域有高度上限并可单独滚动；
- 回归卡整体在较小屏幕上可滚动，A/B/C/D 操作区固定在卡片底部，避免被长文本挤出屏幕。

## 当前原型行为

| 选择 | 行为 |
|---|---|
| `A` | 向当前会话发送“仅依据上一条消息复述明确的任务、约束和期待结果”的请求 |
| `B` | 向当前会话发送“仅依据上一条消息做极简断点汇报”的请求 |
| `C` | 关闭本次回归卡并继续 |
| `D` | 在最短重复提醒间隔内不再提醒当前会话 |

设置通过右下角的 `◷` 按钮打开。可配置总开关、闲置阈值、重复提醒间隔、提醒范围、是否显示时长和欢迎语。

## 安装与兼容性

当前版本为 `0.2.1`。`0.2.0` 已在 DSH 内核 `0.2.0-rc.2` 上完成本机验证；`0.2.1` 是仅调整插件前端布局与本地设置的兼容性更新。声明的兼容范围为：

```text
>=0.2.0-rc.2 <0.2.1
```

可通过 DSH 的插件管理界面或插件命令安装本仓库。也可以下载 GitHub Release 中的 `.tgz` 预构建安装包。

安装或升级前应：

1. 确认 DSH 当前内核落在上述兼容范围内；
2. 备份 desktop profile 的 `package.json` 和 lockfile；
3. 完全退出 DSH Desktop；
4. 通过 DSH 的插件管理通道安装，而不是直接复制文件到 profile；
5. 重启 DSH 后，用一个短闲置阈值测试回归卡和提醒范围。

## 隐私与数据边界

插件在浏览器本地存储中仅保留当前会话的简短断点快照、活动时间、提示关闭时间和工作集标记。它不读取长期记忆、其他会话、外部文件、Git、项目状态或系统活动，也不会改写 DSH 会话日志。
